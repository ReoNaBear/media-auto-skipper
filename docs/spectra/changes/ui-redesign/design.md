## Context

目前三個分頁用 Material 3 預設樣式：`MaterialTheme {}` 無自訂色盤、`NavigationBar` 項目沒有圖示、首頁是幾行文字加一個開關、規則頁把五個區塊平鋪在同一個捲動欄、紀錄頁是無分隔的文字列。介面測試用 `testTag` 與英文字串斷言（`Tags.ENABLE_SWITCH`、`RuleTags`、`PlayerTags`、`HistoryTags` 等）。五種語言的字串在 `strings.xml`。

## Goals / Non-Goals

**Goals:**

- 一致、清楚、符合無障礙基本要求的視覺設計，同時支援淺色與深色。
- 讓使用者一眼看出「現在有沒有在跳歌」、「缺什麼權限」，以及不喜歡功能的代價。
- 保持所有既有測試標籤，讓行為測試不需大改。

**Non-Goals:**

- 任何功能或資料變更；新增畫面；改圖示圖形。

## Decisions

### 設計準則與 token

套用 `penpot-uiux-design` 的預設 token：間距以 8 dp 為基準（4、8、16、24、32）、內文 16 sp、輔助文字 14 sp、標籤 12 sp、卡片圓角 12 dp、按鈕最小高度 48 dp、文字對比至少 4.5:1。色彩只用一個主色加中性色，避免顏色單獨傳達狀態（狀態同時有文字或圖示）。

### 品牌色與主題

新增 `MasTheme`：淺色主色 `#0F766E`、深色主色 `#5EEAD4` 一帶的青綠，與圖示一致；背景與表面用帶一點青綠的中性色；錯誤與警示色沿用 Material 預設。支援系統深色模式（`isSystemInDarkTheme()`），不另設手動開關。字型沿用系統預設字型，只調整字重與大小層級。

### 版面

- 首頁：頂部品牌區（圖示加名稱）、「總開關」大卡片（標題、目前狀態文字、開關，整列可點）、通知存取權狀態卡（已授權為成功樣式，未授權為警示樣式含主要按鈕）、電池最佳化提示卡（次要按鈕）。
- 規則頁：以卡片分組，每張卡片有標題；規則列為「文字加編輯／刪除」，不喜歡選項縮成同一列下方的小選項；不喜歡警示卡放在規則區頂部。
- 紀錄頁：頂部為可橫向捲動的播放器篩選晶片與清除按鈕；每筆為卡片，標題為主要文字，藝人與播放器為次要文字，時間與原因以小標籤顯示，已不喜歡另有強調標籤；空狀態有圖示與一句說明。
- 底部導覽三項各加圖示（自繪向量圖，不新增相依套件）。

### 不喜歡警示文字

`dislike_note` 改為三句：會對播放器送出「不喜歡」；會同步到帳號並影響推薦，本 App 無法取消；會讓跳過變慢且較不可靠（命中後要等約 1.5 到 2 秒，部分播放器可能自己換歌或忽略跳過）。顯示在規則頁的警示卡，五種語言同步。

### 測試相容

保留所有現有 `testTag` 與可點擊語意；新增卡片包裝不改變節點標籤。文字斷言（例如 "cannot undo it"）維持包含在新字串中。截圖用模擬器與假播放器拍攝，英文介面，深色與淺色各看一次但 README 只放淺色三張。

## Implementation Contract

**Behavior**

- 行為與資料完全不變；只有外觀與說明文字改變。
- 規則頁顯示不喜歡警示卡，內容包含「影響帳號推薦」「無法取消」「讓跳過變慢且較不可靠」三點。

**Interface / data shape**

- 新增 `ui/Theme.kt`（`MasTheme`）與少量共用元件（卡片、區塊標題）；保留 `Tags`、`RuleTags`、`PlayerTags`、`HistoryTags` 與各 `*Content` 函式的簽名。
- `strings.xml` 新增或修改的鍵：`dislike_note`（三句版）、導覽與空狀態用到的新字串，五種語言齊全。

**Failure modes**

- 缺少翻譯由 `lintDebug` 的 MissingTranslation 檢查擋下。

**Acceptance criteria**

- `./gradlew testDebugUnitTest :filter-engine:test lintDebug :app:assembleRelease` 全部通過。
- 模擬器上三個分頁在淺色與深色下無文字被截斷或對比不足的情況（目視檢查截圖）。
- 規則頁截圖包含不喜歡警示卡；五種語言各有該警示字串。
- README 的三張截圖是新版畫面。

**Scope boundaries**

- 範圍內：上列畫面、主題、字串、截圖、文件、版本整併。
- 範圍外：功能與資料、圖示圖形、新畫面、Penpot 工具本身。

## Risks / Trade-offs

- **視覺改版破壞既有測試**：以保留標籤與簽名降低風險，並全部重跑。
- **自繪圖示品質**：用簡單的向量路徑，必要時微調；不影響功能。
- **深色主題對比**：只靠目視檢查截圖，沒有自動化對比檢查，屬於未量測項目。
- **截圖不是真機**：模擬器用假資料拍攝，字型渲染可能與真機略有不同。
