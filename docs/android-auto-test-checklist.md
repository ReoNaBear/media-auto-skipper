# Android Auto 實車測試清單

目的：確認手機接上車機後，Media Auto-Skipper 照常跳過符合規則的曲目。App 本身不會出現在車機畫面上，所以判斷成功與否，看的是車機上播放器有沒有換歌，以及事後手機上的「紀錄」分頁。

## 出發前（在手機上）

- [ ] App 已更新到 0.2.0（首頁底部沒有版本號，看「設定 → 應用程式 → 應用程式資訊」）
- [ ] 通知存取權已授予，首頁顯示綠色「已授予」
- [ ] 總開關已開啟（重開機後會自動關閉，要重新開）
- [ ] 電池設定：本 App 已排除於電池最佳化之外
- [ ] 清除跳過紀錄（紀錄分頁 → 清除紀錄），之後比對才不會混淆
- [ ] 準備一份測試播放清單，裡面至少有：
  - 3 首正常的歌（不該被跳過）
  - 2 首標題含簡體字的歌
  - 1 首會命中你自訂關鍵字的歌
- [ ] 一條規則勾選「同時標為不喜歡」，另一條不勾（建議用你本來就不想聽的歌來測，因為不喜歡會寫進帳號）

## 在車上

| # | 做什麼 | 預期結果 | 實際結果 |
| --- | --- | --- | --- |
| 1 | 接上車機，從車機選 YouTube Music 播放測試清單 | 正常歌曲照常播放 | |
| 2 | 播到簡體字標題的歌 | 約 1 秒內自動換下一首 | |
| 3 | 播到命中關鍵字、沒勾不喜歡的歌 | 約 1 秒內自動換下一首 | |
| 4 | 播到勾了不喜歡的規則命中的歌 | 先等約 2 秒再換歌，歌可能會自己先換掉，這是正常的 | |
| 5 | 手機螢幕關閉（鎖定）後重複 2 到 4 | 結果與螢幕亮著時相同 | |
| 6 | 連續放 5 首以上命中的歌 | 連續跳過；每 60 秒超過 20 次才會暫停，暫停時手機會跳出通知 | |
| 7 | 播放中拔掉再接上 USB（或關閉再開啟車機連線） | 重新連上後仍會跳過，不必重開 App | |
| 8 | 如有安裝 YouTube（影片版）或 Spotify，各測一次 2 | 同上；YouTube 影片版偶爾要多等一下 | |
| 9 | 在車機上手動按下一首、上一首、暫停 | 不受 App 影響，沒有被誤跳 | |

## 回家後

- [ ] 打開紀錄分頁，數一數：跳過的曲目是否與車上看到的一致
- [ ] 勾了不喜歡的那幾筆有顯示「已不喜歡」標籤
- [ ] 在 YouTube Music 檢查那幾首的倒讚是否真的亮起；不想保留的，自己取消

## 如果有失敗

記下這幾件事就夠我查：

1. 哪個播放器（YouTube Music、YouTube、Spotify）
2. 哪一項（上表的編號）
3. 當時播放的歌名，以及大約的時間
4. 是完全沒反應、反應很慢，還是跳錯歌
5. 手機型號和 Android 版本，車機品牌

回到電腦後，把手機接上，我可以用 `adb shell dumpsys media_session` 看播放器當時公布了什麼資訊。
